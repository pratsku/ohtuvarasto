# Ohjeet

- Testit on suoritettava komennolla `uv run pytest`.
- `ostos.py`- ja `tuote.py`-tiedostojen koodia ei saa muuttaa.
- Testejä ei saa muokata, ellei sitä nimenomaisesti pyydetä.
- Toteuta aina vain se ehdottomasti välttämätön koodi, joka tarvitaan testien läpäisemiseen.
- Noudata testilähtöistä kehitystä (TDD).
- Älä toteuta toimintoja, joita nykyinen testi ei vaadi.
- Älä koodaa odotettuja testiarvoja kiinteästi koodiin.
- Säilytä kaikki olemassa olevat testit ja toiminnot.
